Allied Care Connect

A multi-agent AI healthcare concierge that routes every question to the right specialist workflow, delivered as part of my role at Codes Logistics.

Context
Codes Logistics, 2026
Role
AI Automation Developer
Stack
n8n, OpenAI API, REST APIs, JSON
Focus
Prompt engineering, guardrails, memory optimisation

Overview

One concierge, five specialists. Every query goes to the sub-workflow that can actually answer it, with zero context leakage between them.

I designed a production-ready multi-agent architecture in n8n. A router sends user queries across specialised sub-workflows for Search, Blog/Resources, FAQs, Analytics and Lead Generation, and each one pulls live practitioner, blog and directory data through REST APIs.
