Type

Overview

Travel planning is scattered across too many tabs. DataSci puts guides, highlights and booking in one place.

The goal was to simplify travel planning with an engaging, visually appealing experience that holds up on every screen size.

Pages

What I built

  1. Fully responsive layout with a consistent UI across all screen sizes.
  2. Destination guides and highlights to help visitors decide where to go.
  3. Integrated booking system inside the same flow.
  4. Smooth animations and interactive hover effects throughout.
